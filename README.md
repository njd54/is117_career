# IS117 Portfolio Research — Frontend vs. Backend Development

## Project Overview

This repository documents my career research and planning for my individual IS117 portfolio project at NJIT.

I am comparing frontend and backend development to understand the responsibilities, technical skills, and expectations of each career. My goal is to use original employer job descriptions to identify which skills I can demonstrate through coursework and which skills I should continue developing.

This research will help guide the design and content of my future professional portfolio.

## Research Question

How do frontend and backend developer responsibilities differ, and what evidence from my existing projects could demonstrate relevant skills to potential employers?

## Careers Being Compared

### Frontend Developer

Frontend developers build the interfaces that people interact with. Their responsibilities can include responsive layouts, accessibility, application performance, and integration with backend APIs.

## Existing Project Evidence

### IS117 — UNBOUND Brand Studio

This project involved creating and improving a T-shirt brand website using HTML, CSS, and JavaScript.

Relevant frontend experience includes:

- Designing and implementing web interfaces.
- Improving responsive layouts and visual presentation.
- Investigating accessibility and color contrast.
- Using GitHub for version control and peer feedback.

### IT490 — Group Event Planner

This project involves developing an event-planning application with PHP, MySQL, RabbitMQ, and the Ticketmaster API.

Relevant backend experience includes:

- Implementing server-side application logic.
- Working with relational databases.
- Processing messages through RabbitMQ.
- Integrating external API data.
- Debugging application communication and database operations.

## Initial Research Direction

The frontend role emphasizes user-facing interfaces, accessibility, and performance.

The backend role emphasizes APIs, database operations, testing, and reliable application behavior.

These observations suggest that my portfolio should demonstrate both the visible application experience and the technical systems supporting it.

This is a proposed portfolio direction, not a claim that all required professional skills have already been demonstrated.
