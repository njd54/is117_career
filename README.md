
# IS117 Portfolio Research — Forward Deployed Engineering vs. Backend Development

## Project Overview

This repository documents my career research and planning for my individual IS117 portfolio project at NJIT.

I am comparing Forward Deployed Engineering (FDE) and Backend Development to understand the responsibilities, technical skills, and expectations of each career. My goal is to use original employer job descriptions to identify which skills I can demonstrate through coursework and which skills I should continue developing.

Although both careers interest me, I am currently more interested in backend development because I enjoy working with databases, APIs, server-side logic, and communication between application components.

This research will help guide the design and content of my future professional portfolio.

## Research Question

How do Forward Deployed Engineer and Backend Developer responsibilities differ, and what evidence from my existing projects could demonstrate relevant skills to potential employers?

## Careers Being Compared

### Forward Deployed Engineer (FDE)

Forward Deployed Engineers work with clients to understand technical problems and develop software solutions that address specific business needs.

Their responsibilities can include system integration, software development, client collaboration, deployment, and troubleshooting.

**Employer researched:** Provectus

**Position:** Associate Forward Deployed Engineer

**Original source:** https://jobs.lever.co/provectus/62394851-693e-47fe-a86c-f8d9acf43ec2

**Date checked:** November 11, 2026

The Provectus role emphasizes developing AI-powered applications, understanding client requirements, and helping deploy technical solutions.

### Backend Developer

Backend developers work on the systems that support applications, including APIs, databases, business logic, security, and server-side performance.

**Employer researched:** Ketryx

**Position:** Backend Engineer

**Original source:** https://job-boards.greenhouse.io/ketryx/jobs/5192824008

**Date checked:** November 11, 2026

The Ketryx role emphasizes backend APIs, PostgreSQL databases, testing, and application reliability.

## Existing Project Evidence

### IS117 — UNBOUND Brand Studio

This project involved creating and improving a T-shirt brand website using HTML, CSS, and JavaScript.

Relevant experience includes:

- Designing and implementing web interfaces.
- Improving responsive layouts and visual presentation.
- Investigating accessibility and color contrast.
- Using GitHub for version control and peer feedback.

Although this project focuses on frontend development, it demonstrates my understanding of how users interact with web applications and how frontend systems support the overall user experience.

### IT490 — Group Event Planner

This project involves developing an event-planning application with PHP, MySQL, RabbitMQ, and the Ticketmaster API.

Relevant backend and system integration experience includes:

- Implementing server-side application logic.
- Working with relational databases.
- Processing messages through RabbitMQ.
- Integrating external API data.
- Debugging application communication and database operations.

This project relates to Backend Development because it involves database operations, server-side functionality, and communication between application components.

It also relates to Forward Deployed Engineering because it involves integrating multiple technologies and troubleshooting technical problems to build a functioning application.

However, this project does not currently demonstrate direct client collaboration or production AI deployment.

## Initial Research Direction

The Forward Deployed Engineer role emphasizes client collaboration, software integration, AI-powered applications, and deployment.

The Backend Developer role emphasizes APIs, database operations, testing, and reliable application behavior.

Both careers require programming, problem-solving, and an understanding of how software systems communicate.

Based on my research and coursework experience, I am currently more interested in backend development.

These observations suggest that my portfolio should demonstrate both my technical backend contributions and my broader understanding of application development.

This is a proposed portfolio direction, not a claim that all required professional skills have already been demonstrated.

## Research-to-Portfolio Decisions

### Decision 1: Highlight Backend Architecture

**Research finding:** The Ketryx Backend Engineer role emphasizes API development, database operations, and reliable application behavior.

**Portfolio decision:** Create a technical case study for my IT490 Event Planner project that explains how the frontend, RabbitMQ broker, backend, and database communicate.

**Planned verification:** Review the application code and confirm that the architecture diagram accurately represents the implementation.

### Decision 2: Demonstrate System Integration

**Research finding:** The Provectus Forward Deployed Engineer role emphasizes understanding technical requirements, integrating software, and developing practical solutions.

**Portfolio decision:** Explain how my Event Planner project integrates RabbitMQ, MySQL, PHP, and external API data.

**Planned verification:** Document a real technical problem encountered during development, the troubleshooting process, and the resulting outcome.

### Decision 3: Include User-Facing Project Evidence

**Research finding:** Both engineering careers benefit from understanding how technical systems support real applications.

**Portfolio decision:** Include my IS117 UNBOUND project to demonstrate web interface development, responsive design, and accessibility improvements.

**Planned verification:** Review the published website, verify the relevant source code, and confirm that any screenshots accurately represent the project.
