Research to Portfolio Decisions

My research into Forward Deployed Engineering and Backend Development helped me identify which technical skills employers emphasize and how I could demonstrate those skills through my coursework. The following decisions connect research findings to proposed portfolio features.

1. Backend Development: APIs and Databases

Research finding: The Ketryx Backend Engineer job description emphasizes API development, database operations, testing, and application reliability.

Portfolio decision: Include a technical case study of my IT490 Event Planner project. This will explain how PHP, MySQL, RabbitMQ, and the Ticketmaster API work together to support the application.

Planned verification: Review the project's source code and create an architecture diagram showing communication between the frontend, RabbitMQ broker, backend, and database.

2. Forward Deployed Engineering: System Integration

Research finding: The Provectus Associate Forward Deployed Engineer job description emphasizes understanding client requirements, developing AI-powered applications, integrating systems, and deploying technical solutions.

Portfolio decision: Highlight the system integration work completed during my IT490 Event Planner project. Explain how RabbitMQ, PHP, MySQL, and external API data are used together to support application functionality.

Planned verification: Review the Event Planner code and document a real technical problem encountered during development, including the troubleshooting process and resulting outcome.

3. Portfolio Structure: Demonstrating Skills

Research interpretation: Both career paths require practical technical skills that are easier to evaluate when supported by examples of completed work.

Portfolio decision: Organize the portfolio around individual projects, with explanations of my contributions, technologies used, and links to relevant code or documentation.

My IS117 UNBOUND project will provide additional evidence of frontend development, responsive design, and accessibility work.

Planned verification: Ask a peer reviewer to navigate the portfolio and determine whether the research findings connect clearly to the proposed features.

Research sources: Ketryx Backend Engineer and Provectus Associate Forward Deployed Engineer . Both positions were researched during the November 11, 2026 research round. Some Provectus posting details, including current application availability, still require independent verification.

These features are proposed improvements, not claims that the implementation or testing has already been completed.
