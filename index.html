Research to Portfolio Decisions

My research into frontend and backend development helped me identify which technical skills employers emphasize and how I could demonstrate those skills through my coursework. The following decisions connect research findings to proposed portfolio features.

1. Backend Development: APIs and Databases

Research finding: The Ketryx Backend Engineer job description emphasizes API development, database operations, testing, and application reliability.

Portfolio decision: Include a technical case study of my IT490 Event Planner project. This will explain how PHP, MySQL, RabbitMQ, and the Ticketmaster API work together to support the application.

Planned verification: Review the project's source code and create an architecture diagram showing communication between the frontend, RabbitMQ broker, backend, and database.

2. Frontend Development: Accessibility and Design

Research finding: The Xsolla Junior Frontend Developer description highlights interface development, performance, accessibility, and frontend frameworks.

Portfolio decision: Highlight my IS117 UNBOUND project with screenshots and explanations of its responsive layout, accessibility improvements, and frontend implementation.

Planned verification: Inspect the published UNBOUND website and review its HTML, CSS, and JavaScript to confirm that the portfolio descriptions accurately represent the completed work.

3. Portfolio Structure: Demonstrating Skills

Research interpretation: Both career paths require practical technical skills that are easier to evaluate when supported by examples of completed work.

Portfolio decision: Organize the portfolio around individual projects, with explanations of my contributions, technologies used, and links to relevant code or documentation.

Planned verification: Ask a peer reviewer to navigate the portfolio and determine whether the research findings connect clearly to the proposed features.

Research sources: Ketryx Backend Engineer and Xsolla Junior Frontend Developer . Both sources were checked during the November 11, 2026 research round. Some Xsolla details still require independent verification.

These features are proposed improvements, not claims that the implementation or testing has already been completed.
