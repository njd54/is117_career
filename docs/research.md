**Course:** IS117-007 — Portfolio Research

## 1. Research Question

How do Forward Deployed Engineer (FDE) and Backend Developer responsibilities differ, and how can I use my existing coursework to demonstrate relevant technical skills in a professional portfolio?

This research compares two employer job descriptions and identifies evidence that can guide my portfolio design.

## 4. Comparison of the Roles

| Category | Forward Deployed Engineer | Backend Developer |
|---|---|---|
| Primary focus | Client-specific technical solutions | Server-side application systems |
| Example technologies | Python, TypeScript, AWS | TypeScript, PostgreSQL, GraphQL |
| Main responsibilities | Client collaboration, AI solutions, deployment | APIs, databases, reliability |
| Collaboration | Clients, senior engineers, stakeholders | Frontend developers, product teams |
| Existing coursework connection | IT490 system integration | IT490 backend development |

Both roles require programming, problem-solving, and an understanding of how software systems communicate.

The FDE role places additional emphasis on working directly with clients and implementing solutions for their specific needs.

## 5. Evidence vs. Assumptions

### Evidence from Employer Sources

- Provectus describes developing AI-powered applications and collaborating with clients.
- Provectus identifies Python or TypeScript, cloud deployment, and technical communication as relevant skills.
- Ketryx identifies API development, database operations, testing, and application reliability as responsibilities.
- Ketryx requires at least three years of full-time industry experience.

### Interpretations and Assumptions

- Backend development may align more closely with my interest in server-side programming and database operations.
- Forward Deployed Engineering may be useful for someone who enjoys combining technical development with client communication.
- A portfolio showing application architecture and working project examples could demonstrate skills relevant to both roles.

These interpretations are conclusions drawn from the research rather than direct employer requirements.

## 7. Alternatives Considered

**Option A: Backend-focused portfolio**

Advantages:
- Highlights databases, APIs, and application architecture.
- Supports discussion of technical problem-solving.

Limitation:
- Backend functionality can be difficult to demonstrate visually.

**Option B: Forward Deployed Engineering-focused portfolio**

Advantages:
- Highlights system integration and technical problem-solving.
- Demonstrates how software can address practical requirements.

Limitation:
- My current coursework provides limited evidence of direct client collaboration and AI deployment.

**Option C: Full-stack portfolio with a backend emphasis**

Advantages:
- Demonstrates both interface and server-side experience.
- Allows employers to inspect different types of project evidence.
- Supports my interest in backend development while showing broader technical knowledge.

Limitation:
- Requires clear organization to prevent the portfolio from becoming unfocused.

**Proposed decision:** Use a full-stack portfolio structure with a backend emphasis and separate explanations of my technical contributions.
